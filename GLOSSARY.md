# Glossary

**Collection**: A named group of items in the Zotero library (e.g. "pySUTO").

**Exported Collection** (Export): A dated snapshot of one Collection written as a JSON and a Markdown report. A Collection can have several Exports; "the" Export means the latest one.

**Item**: One bibliographic entry (paper, book, ...) in a Collection, with its metadata and abstract.

**Annotation**: A mark made in an Item's attachment: a highlight, underline, sticky note or image. Highlights and underlines carry the source's text and a page.

**Comment**: Text the user attached to an Annotation. The user's words, not the source's.

**Note**: A free-standing text the user wrote on an Item. The user's words, not the source's.

**Quote**: Verbatim text from the source (highlight/underline text or abstract) with its attribution. Comments and Notes are only quotable when labelled as the user's own.
